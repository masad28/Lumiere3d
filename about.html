About This Project

LUMIÈRE 3D is an interactive Web 3D application created for my Web 3D Applications module. The project presents three luxury perfume concepts: Rose Bloom, Ocean Mist and After Midnight.

3D Models

The perfume bottles were created in Blender using simple geometric modelling techniques. I used cylinder-based modelling, extrusion, scaling and smoothing to create a the bottle shapes. Each perfume model has its own colour palette, label and material design.

Technologies Used

The website was built using HTML5, CSS3, Bootstrap, JavaScript and Three.js. Blender was used to create the 3D models, which were exported as OBJ and MTL files and loaded into the webpage.

Interaction Features

Users can rotate the selected model, switch wireframe mode on and off, use orbit controls to zoom and pan, and select different perfume models through the gallery buttons.

Design Choices

I designed the website with a luxury fragrance aesthetic using soft colours, metallic abstract imagery, rounded cards, dark contrast sections and clean typography. The visual style was chosen to match the perfume models and create a consistent product showcase.

Accessibility

The layout uses clear headings, readable contrast, large buttons and a responsive Bootstrap grid. The content is organised into sections so users can understand and navigate the page easily.

Deeper Understanding

This project extends beyond the laboratory tutorials through the creation of original Blender perfume models, implementation of OBJ/MTL model loading, dynamic 3D model swapping, responsive Bootstrap design, custom camera systems and additional interactive JavaScript features such as wireframe mode, orbit controls and audio feedback.

Testing

I tested the model viewer, rotation button, wireframe button, orbit controls and model switching buttons. I also checked that the website layout responds correctly when the browser window is resized. Testing identified several issues during development, including incorrect model scaling, broken file paths and camera orientation problems. These issues were resolved through iterative refinement of the Three.js scene and Blender exports.

Accessibility Considerations

High contrast buttons, readable typography and responsive layouts were used to improve accessibility and usability. Interactive controls were clearly labelled and organised consistently throughout the interface.
